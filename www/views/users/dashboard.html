Species Breakdown

SCOPE The identification feature is trained on seagrass species documented in the Negros region. The species information library covers an estimated 60–72 species worldwide for reference — but only Negros-documented species will return a confident classification result from the CNN model.

Tips for Better Identifications

  • Use clear, well-lit images taken in shallow water or at the surface.
  • Frame a single plant or patch — avoid cluttered multi-species shots for initial ID.
  • Capture the leaf shape, tip, and any visible veins; these are key classification features.
  • For quadrat assessments, photograph each quadrat from directly above.
  • Rinse lenses of underwater cameras before shooting to reduce distortion.
  • Low-visibility or blurry images will reduce model confidence — retake if possible.

About the Identification Model

  • Classification is performed by a Convolutional Neural Network (CNN) trained on labeled seagrass images.
  • The model outputs a species prediction alongside a confidence score — lower scores suggest ambiguous images.
  • Only species present in the Negros region dataset are within the model's trained scope.
  • Results should be reviewed by the researcher; the system does not replace expert field assessment.
  • Assessment outputs include species composition, abundance, and percentage cover estimates.
