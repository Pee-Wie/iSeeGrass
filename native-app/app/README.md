# native-app/app

This directory is the Android app module for the iSeeGrass native application.

## What's missing from this repo

The `src/` folder is intentionally excluded from version control.  
It contains the full Java source code for the Android app and is managed separately.

To get the source:
- Contact the project maintainer, or
- Check the private source repository if you have access.

## What's here

- `build/` — excluded (Android build output, generated by Gradle)
- `src/` — excluded (Android app source code, managed separately)

## Structure (when fully set up)

```
app/
├── src/
│   └── main/
│       ├── java/com/iseegrass/native_app/   ← Java source
│       ├── res/                              ← layouts, drawables, strings
│       └── AndroidManifest.xml
└── build.gradle                              ← app-level Gradle config
```
